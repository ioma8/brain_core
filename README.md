# brain_core

Rust library for working with mind maps: parsing FreeMind (`.mm`), XMind, MindNode and OPML formats into a unified `Node`/`MindMap` model, with optional storage.

Used by [BrainRust](https://github.com/ioma8/BrainRust).

## Formats

- FreeMind (`.mm`) — `mmap.rs`
- XMind — `xmind.rs`, `smmx.rs`
- MindNode — `mindnode.rs`
- OPML — `opml.rs`
